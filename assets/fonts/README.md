# Shared local fonts

Both HTML pages load these unmodified official WOFF2 files through [hitl-typography.css](../hitl-typography.css). No font CDN or build step is needed.

- **Inter 4.1:** `web/InterVariable.woff2` from the [official stable release](https://github.com/rsms/inter/releases/tag/v4.1). The original `LICENSE.txt` is preserved as [inter-license.txt](inter-license.txt).
- **JetBrains Mono 2.304:** Regular, Medium, SemiBold and Bold from `fonts/webfonts/` in the [official stable release](https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304). The original `OFL.txt` is preserved as [jetbrains-mono-license.txt](jetbrains-mono-license.txt).

Versions were checked against the official release APIs on 2026-10-06. Both fonts use the SIL Open Font License 1.1. Font family names and glyphs are unchanged.
